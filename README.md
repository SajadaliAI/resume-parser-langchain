# Resume Parser using LangChain & Groq LLM

AI-powered **Resume Parser** that extracts structured information from resumes (PDF, DOCX, TXT) and returns it as **JSON output**.

---

## Features

- Extracts: Name, Email, Phone, LinkedIn, Skills, Education, Experience, Projects, Certifications, Languages
- Preview extracted resume text
- Returns structured JSON using **Groq LLM**
- Built with **Streamlit** for interactive web UI

---

## Tech Stack

- Python 3.11+
- LangChain
- Groq LLM
- Streamlit
- python-dotenv
